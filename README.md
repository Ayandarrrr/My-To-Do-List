# My To-Do List

## Project Overview

My To-Do List is a simple and interactive task management application built using HTML, CSS, and Vanilla JavaScript. The application allows users to add, manage, and organize daily tasks efficiently through a clean and user-friendly interface.

This project was created to strengthen my understanding of JavaScript fundamentals, DOM manipulation, event handling, and user interaction.

## Features

* Add new tasks
* Mark tasks as completed
* Delete tasks
* Responsive user interface
* Dynamic task management using JavaScript
* Simple and clean design

## Technologies Used

* HTML5
* CSS3
* Vanilla JavaScript

## Learning Objectives

Through this project, I improved my understanding of:

* JavaScript fundamentals
* DOM manipulation
* Event listeners
* Functions and arrays
* User input handling
* Responsive web design

## How to Run the Project

1. Clone the repository:

```bash
git clone https://github.com/Ayandarrrr/My-To-Do-List.git
```

2. Open the project folder.

3. Launch the `index.html` file in your browser.
